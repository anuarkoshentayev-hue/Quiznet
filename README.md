# Қазақстан тарихы — 4-ай, 2-апта (Онлайн Тест)

ҰБТ-ға дайындыққа арналған **135 сұрақтан** тұратын интерактивті онлайн тест платформасы.

## Мүмкіндіктері
- **4 тақырыптық бөлім** немесе барлық 135 сұрақты бірге тапсыру
- **Жаттығу режимі**: жауап берген бойда дұрыс/бұрыстығын бірден көрсетеді
- **Емтихан режимі**: таймермен нақты тест тапсыру форматы
- **Араластыру**: сұрақтар ретін және жауап нұсқаларын кездейсоқ араластыру
- **Қатемен жұмыс**: тест соңында тек қате жауап берілген сұрақтарды қайта тапсыру

## GitHub Pages арқылы іске қосу
1. Осы репозиторийді GitHub-қа жүктеңіз (`index.html`, `README.md`, `.nojekyll`).
2. Репозиторий баптауларынан **Settings → Pages** бөліміне өтіңіз.
3. **Branch** ретінде `main` (немесе `master`) және `/ (root)` папкасын таңдап **Save** батырмасын басыңыз.
4. Бірнеше секундтан кейін сайт сілтемесі дайын болады.
